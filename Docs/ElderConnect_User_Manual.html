What Is ElderConnect?

Project overview and dual-portal architecture

ElderConnect is a cross-platform mobile application designed for elderly users aged 60 and above. It combines social connection, AI-powered mood detection, personalised news, health management, and a caretaker monitoring dashboard — all in one app with an elderly-first accessible design.

🏠 Elder Portal

Simplified interface designed for zero digital literacy. Accessible by 4-digit PIN only — no email, no password to remember.

👨‍⚕️ Caretaker Portal

Full monitoring dashboard. Manage medications, view mood trends, receive alerts, and manage elder links.

🧠

AI Mood Detection

MOSAIC engine analyses elder posts using Hugging Face NLP and tracks mood trends over 7 days.

💊

Medication Reminders

Caretakers set schedules; elders confirm or miss doses with one tap. Logged for the caretaker.

📰

Personalised News

Articles filtered by each elder's interests (cricket, gardening, music etc.) and current mood.

🎮

Wellness Games

Memory, trivia, and relaxation games. Scores are tracked and contribute to the activity summary.

🆘

Emergency Button

One-tap emergency contact — always visible. Separate high-visibility SOS for real emergencies.

🔊

Text-to-Speech

Reads feed content and news articles aloud for visually impaired elders.

Installation

Installing the app on an Android device

The app is distributed as a pre-built APK. No Play Store listing is required for testing.

  1. Enable Unknown Sources. On the Android device, go to Settings → Apps → Special App Access → Install Unknown Apps and allow your file manager or browser.
  2. Transfer the APK. Copy app-release.apk to the device via USB, Google Drive, or email.
  3. Install. Open the APK from your file manager and tap Install. The app icon labelled ElderConnect will appear on the home screen.
  4. Grant permissions. On first launch the app requests microphone (Talk Button) and notification (medication reminders) permissions. Tap Allow for both.
ℹ️
Internet Required
ElderConnect requires an active internet connection. All data is stored in the cloud (Supabase). PIN login and feed content will not work offline.

First Launch

Splash screen and role selection flow

  1. App opens to an animated Splash Screen. After ~2 seconds it auto-navigates based on any stored session.
  2. If no saved session is found, the Role Selection screen appears. Tap "I am an Elder" or "I am a Caretaker / Family Member".
  3. If a previous session exists (e.g. already logged in as Pawan), the app goes directly to the appropriate home screen — skipping login entirely.

All screens and features accessible to elderly users.

PIN Login

Elder authentication with 4-digit PIN

Elders never type an email or password. Login is a single 4-digit PIN. The PIN is matched against a secure bcrypt hash stored in the database.

  1. On the Role Selection screen tap "I am an Elder".
  2. The Elder PIN Login screen shows 10 large tap-target digit buttons. Tap your 4-digit PIN. The dots fill in as you tap.
  3. After 4 digits are entered, the app automatically verifies — no submit button to press. A loading indicator appears briefly.
  4. On success, the app navigates to the Elder Home Screen and saves the session locally. Future opens skip this step.
💡
Wrong PIN
If the PIN is wrong, the dots shake and reset. The elder can try again immediately. There is no lock-out during testing. Tap "Need Help" at the bottom to contact a caretaker.

Home Screen

Elder dashboard — the main hub

The Home Screen is the elder's daily landing page. It shows a personalised greeting, the current date, medication reminders, a mood card, connect prompt, emergency access, and a wellness tip.

👋

Shows "Good Morning/Afternoon/Evening, [Name]!" and today's real date (e.g. Saturday, 25 April 2026).

💊

Medical Reminder Card

Lists all active medications. Each has a YES, I TOOK IT and NO, I DIDN'T button. Both responses are logged for the caretaker.

😊

Mood Card

Displays the latest detected mood with emoji. Derived from AI analysis of the elder's recent posts.

👥

Connect Card

Quick access to the social feed and a prompt to share something with friends and family.

🆘

Emergency Section

Emergency Dial (amber) contacts the linked caretaker. SOS button (red) for serious emergencies.

💡

Wellness Tip

A rotating daily tip from the wellness library — breathing, hydration, gratitude etc.

Social Feed

Share posts, photos, and voice messages

The Feed tab shows posts from the elder and their linked family/caretaker network, alongside personalised news articles.

Posting

  1. Tap the large compose button (pencil icon, bottom right).
  2. Type a message in the text field. The font size is large (18sp) for easy reading.
  3. Optionally tap the photo icon to attach an image from the gallery or camera.
  4. Tap Post. The post appears in the feed and is analysed by the MOSAIC AI for mood.

Voice Messages (Talk Button)

  1. Tap and hold the microphone button.
  2. Speak your message. Release to send.
  3. Audio is stored and playable by recipients. Voice is not processed by mood AI.
🧠
AI Mood Analysis
Every text post is automatically analysed by the Hugging Face NLP model. The mood result (POSITIVE / NEUTRAL / NEGATIVE) is stored and visible to the caretaker on their Mood History page — only if the elder has consented.

Wellness Games

Memory, trivia, and relaxation activities

Tap the Games tab to access four wellness activities. Scores are saved to the wellness log and visible to the caretaker on their dashboard.

🧩

Memory Match

Flip cards and match pairs. Trains short-term memory. Score is time-based.

❓

Daily Trivia

General knowledge questions with large tap targets. 10 questions per session.

🌬️

Breathing Exercise

Animated breathing guide — inhale, hold, exhale. Tracks completed sessions.

Relaxation

Guided relaxation prompts with background soundscapes.

Medications Tab

View schedule and confirm doses

The Medications tab only appears in the bottom nav when a caretaker has added at least one medication for this elder. It has two sections.

📋

My Medications

Lists all active medications assigned by the caretaker — pill name, colour, and dosage. Read-only; managed by caretaker.

⏰

Up Next & History

Shows the next scheduled dose and a history of taken/missed logs. Logs are created automatically by the server at scheduled times.

🏠
Home Screen Card vs Medications Tab
The Medical Reminder Card on the home screen is a daily check-in for all medications — elder taps YES or NO to log the response. The Medications Tab shows the complete schedule and full history.
📰

News Feed

Personalised articles based on interests and mood

News articles appear in the Feed tab below the social posts. Articles are fetched from NewsAPI.org and filtered by each elder's interest tags set at registration.

  1. Scroll down in the Feed tab to see article cards.
  2. Tap any article card to open a bottom sheet reader with font size optimised for elders.
  3. Tap the speaker icon to have the article read aloud using text-to-speech.
  4. Tap Read Full Article to open the original source in a browser tab within the app.
  5. The feed infinite-scrolls — keep scrolling past articles to load more (10 per page).
🔊

Text-to-Speech

Audio reading for visually impaired elders

TTS is controlled per-elder from their profile. When enabled, a speaker icon appears on posts and news cards.

  1. Go to Profile (avatar in top-right).
  2. Toggle "Read content aloud (Text-to-Speech)" to ON.
  3. Return to the Feed. Each post and article card now shows a 🔊 speaker button.
  4. Tap the speaker button to hear the content read aloud. Tap again to stop.

Emergency & SOS

One-tap emergency contact system

🚨
Emergency Features Are Live
The Emergency Dial and SOS button trigger real notifications to the linked caretaker's device. Use with caution during demos.
📞

Emergency Dial (Amber)

Calls or messages the linked caretaker. Displayed as a warm amber button. Use for non-critical situations like needing assistance.

🆘

SOS Button (Red)

Reserved for genuine emergencies only. Sends an urgent FCM alert to all linked caretakers. Red colour distinguishes this from the general emergency button.

Profile

View and edit elder's personal settings

Access by tapping the avatar circle in the top-right of the app bar.

  • View name, date of birth, and profile photo
  • Update interest tags (affects news feed personalisation)
  • Toggle Text-to-Speech on or off
  • View mood sharing consent status
  • Sign out (returns to Role Selection screen)

Login & Registration

Caretaker email/password authentication

Logging In (Existing Account)

  1. On Role Selection tap "I am a Caretaker / Family Member".
  2. Enter your email address and password.
  3. Tap Sign In. You are taken to the Caretaker Dashboard.

Creating a New Account

  1. On the Login screen tap "Create Account".
  2. Enter your full name, email address, phone number, and a password.
  3. Tap Register. You are taken to the dashboard immediately — no email confirmation required for testing.
📊

Caretaker Dashboard

Live overview of all linked elders

The Dashboard (Tab 1) shows a priority alert card and a scrollable list of cards for each linked elder. All data updates in real-time.

🚨

Priority Alert Card

Highlights any elder with a WARNING or URGENT mood state. Tapping navigates to their mood history.

👴

Elder Summary Cards

One card per linked elder showing mood status, latest post, activity count, and medication adherence today.

📈

Activity Stats

Posts created, games played, and medications taken — all for the current day.

🔔

Push Notifications

FCM alerts arrive when: medication is missed, mood deteriorates, or an SOS is triggered.

💊

Medication Manager

Add and manage medications for linked elders

The Medications tab (Tab 2) lets caretakers add, edit, and deactivate medications for any linked elder.

Adding a New Medication

  1. Tap the + Add Medication button.
  2. Select the elder from the dropdown.
  3. Enter: Pill name (e.g. Metformin), dosage (e.g. 500mg), and pill colour.
  4. Add one or more reminder times (e.g. 08:00, 20:00).
  5. Tap Save. The medication immediately appears in the elder's app on their home screen and Medications tab.
✅
Instant Sync
Medications use Supabase Realtime. As soon as you save, the elder's app updates — no refresh needed.

Medication Log

Each reminder time creates a medication log entry when the scheduled time passes. The elder's YES/NO response updates the log to taken or missed. You can view the full history per elder in the Medications tab.

📉

Mood History

View 7-day mood chart and activity summary

The Mood History tab (Tab 3) shows a bar chart of the elder's mood intensity over the last 7 days, their recent posts, and activity summary.

🔒
Consent Required
Mood data is only visible here if the elder has mood_sharing_consent = true on their profile. All 6 test elders have consent enabled.
  • Use the elder selector at the top to switch between linked elders
  • The 7-day bar chart shows mood intensity (0.0–1.0) per day
  • Below the chart: Recent Posts from this elder
  • Activity summary: posts, games, and medication adherence for the past 7 days
  • Alert state badge: STABLE (green) / WARNING (amber) / URGENT (red)
🔗

Linking Elders

Search and link new elderly users to your account

Without a link, a caretaker cannot see any elder's data. Links are managed from the Settings tab (Tab 4) in the caretaker portal.

Searching for an Elder

  1. Go to Settings → Manage Elder Links.
  2. Tap Search & Link Elder.
  3. Search by the elder's full name or phone number.
  4. Tap the elder's name in results and tap Send Link Request.
  5. Once accepted (or auto-accepted in test mode), the elder appears on your dashboard.
⚠️
Pre-seeded Links Only in Testing
The 6 demo elders are already linked to their respective caretakers in the database. You do not need to re-link them. Searching and linking is for testing the registration flow with a new/registered elder account.

AI Features — MOSAIC

Multi-signal mood intelligence engine

MOSAIC (Multi-signal Observation of Sentiment and Affect with Intelligent Caretaker alerts) is the AI backbone of ElderConnect. It does NOT just detect mood from a single message — it fuses multiple signals over time.

🔬
Academic Framing
MOSAIC uses a two-layer architecture: (1) real-time emotion classification via Hugging Face Inference API (transformer NLP model), and (2) longitudinal trend analysis with sliding-window statistics over 7 days to detect deteriorating patterns.

How Mood Is Detected

SignalSourceWeight
Text Sentiment AI Post text → Hugging Face j-hartmann/emotion-english-distilroberta-base 40%
Self-Report Discrepancy Emoji tap vs NLP inference delta 20%
Social Activity Post & interaction count from posts table 20%
Routine Adherence Medication logs taken / total from medication_logs 20%

Alert Levels

✅

STABLE

Mood trend flat or improving. No alert sent. Dashboard shows positive weekly summary.

⚠️

WARNING

Negative slope for 3+ consecutive days. Push: "Consider checking in with [Name]".

🚨

URGENT

Severe decline 5+ days or single-day crash below threshold. Urgent FCM with emergency contact prompt.

Accessibility Design

Built for zero digital literacy

46.2% of elderly survey respondents needed help completing a paper form. ElderConnect is designed to be self-explanatory for someone who has never used a smartphone application.

Accessibility RuleImplementation
Minimum tap target48 × 48 logical pixels on all interactive elements
Minimum font size16sp — never below this in any screen
Body text18sp default throughout
Button labels20sp bold
Colour contrastWCAG 2.1 AA — 4.5:1 normal text, 3:1 large text
No dark modeLight mode only — high contrast by default
Semantic labelsAll icon buttons have Semantics wrappers for screen readers
Touch spacing≥ 8dp gap between adjacent touch targets
Colour as differentiatorNever used alone — always paired with icon or label

Troubleshooting

Common issues and solutions

🔴

"Invalid PIN" on every attempt

Ensure the APK was built with the correct Supabase anon key. If using an older APK, reinstall from the latest build. See test account PINs table above.

📡

Feed shows no posts or news

Check internet connection. News requires the NEWS_API_KEY to be set in the build. If articles are missing, the API key may have expired — rotate at newsapi.org.

💊

Medication tab not showing

The tab only appears when the linked caretaker has added at least one active medication. Log in as the caretaker and add a medication from the Medications tab.

😐

Mood always shows NEUTRAL

The Hugging Face model may be in cold-start mode (first request takes ~25 seconds). Post some text and wait. If the model returns an error, the system gracefully falls back to NEUTRAL.

🔔

Not receiving push notifications

FCM notifications require Firebase to be configured and notification permissions granted. Ensure the device has allowed notifications for ElderConnect in Settings → Apps.

🚪

Stuck on splash screen

This usually means a stale session token. Clear app data from Android → Settings → Apps → ElderConnect → Clear Data, then reopen and log in.

👁️

Caretaker cannot see elder's mood data

Mood data is protected by RLS. Check that mood_sharing_consent = true on the elder's user row in Supabase. All test elders have this enabled.

🔗

No linked elders on caretaker dashboard

Ensure you logged in as the correct caretaker account. Each caretaker is only linked to 2 specific elders (see test accounts table). There is no cross-linking in test data.
